第一阶段版本：v1.0.0，2026-11-08。

## 本次交付

- 本地 Web、Windows 桌面入口、FastAPI 和 SQLite 迁移。
- 媒体上传与预览、MiMo 画面理解、联网事实核查、七阶段任务与创作脚本。

- README、完整项目说明书、架构、模块说明、运行维护和验收记录。

## 使用

按 README 安装 Node.js、Python 和项目依赖，运行 setup.ps1、start.ps1；需要桌面图标时执行 install-desktop.ps1。模型 Key 由使用者在本机 .env 配置。

## 交付边界

仓库保存源码与静态资源，排除密钥、账号凭证、数据库、客户上传、日志、原始导出资料、依赖及本机运行包。新机器需要重新初始化环境。订单收入按接单记账，尚未发生支付网关收款；模型费用为估算。公网、真实资金、外部发布及自动转录仍待后续配置或开发。
