# 工程决策 · 2026-11-07

- 依据 CODEX_TASK.md 的完整授权直接实施，无逐阶段确认。设计与计划技能用于拆分工程、测试和验收。
- 本地 Next.js App Router + FastAPI + SQLAlchemy/Alembic + SQLite；PostgreSQL 通过 DATABASE_URL 替换。无需 Docker，不发布公网。
- 三个并行模块：Web、AI/Agent、研究与商务；主工程负责数据库、认证、素材、安全、集成和验收。
- Next.js 同源代理 /api，HttpOnly 会话；所有业务查询按 organization_id 隔离，老板身份由初始化命令建立。
- 数据库持久化任务和步骤。单机工作线程推进，启动时将中断任务标为失败并允许重跑；成功节点缓存复用。
- MiMo 仅在用户明确点击 AI 分析后调用。服务状态检查只使用模型列表接口；模型费用是可配置单价估算。
- 不做外部抓取/公开存储上传/真实支付。真实支付、公开发布、退款及删除用户数据必须人工审批，缺少供应商授权时不能执行。
- UI 采用深墨色导航、浅色研究工作台、青绿色强调色；展示来源、证据和数据缺失，Demo 数据显著区分。
- 不引入生成图像/视频能力。媒体处理只使用项目依赖提供的 FFmpeg、Pillow 和场景检测。
- 当前目录为空白工程，无既有 Git 分支需隔离；直接在用户指定目录开发。
- 本机 Turbopack 的 CSS 子进程出现启动失败，切换到 Next.js 支持的 webpack 构建并通过验收。
- MiMo Pro 仅输出创作建议草案。服务端使用已验证的内容观察和确定性数据合成报告，避免二次生成证据导致结构偏差。
