# CreatorOS v1 · 研究与商务说明

研究逻辑位于 `business_research.py`，当前商业流程以 `business_commerce.py` 为准；`business.py` 负责组合路由。完整使用说明见 PROJECT_GUIDE.md。

## 研究数据

创作者档案、作品库、指标和实验均按组织限定。对标资料支持 CSV/XLSX、匹配封面、排序筛选和收藏，保留来源及导入指纹。链接仅保存显示，后端不任意抓取。Demo 必须显式导入，并在当前实际经营统计中排除。

指标预览支持字段映射，缺失数值保留空值；批次有来源和指纹，可追溯或删除对应导入记录。研究实验保留作品／分析关联、计划修改、假设、目标指标、观测窗口及版本快照，允许后续挂接观察资料，不把一次变化解释为已证明因果。

## 客户与线索

新线索需要登录客户身份，使用客户用户 ID 和组织 ID 关联。历史完整邮箱匹配受限处理；用户不能通过提交别人的联系方式绑定他人记录。老板内部备注不外发，单独的客户回复进入对应客户“服务与反馈”。

## 服务与订单

服务配置按价格升序返回，首页、套餐选择和后台以服务端数据为准，订单保留价格与服务快照。

- 客户直接确认服务后创建 REQUESTED 订单。
- 报价需要人工审批，生成 AWAITING_CUSTOMER 订单后由客户确认。
- 老板接单后 IN_PROGRESS；重复接单不重复记账。
- 完成服务或交付成功报告后 DELIVERED。
- 客户二次确认验收后 COMPLETED，保留确认时间与规则版本。

工单与订单可关联，工单不会自动生成订单。退款等高风险请求进入审批；当前未接入真实退款调用。

## 统计口径

当前订单收入表示真实注册客户确认、老板已接单的订单金额，并非支付网关实收。历史 Demo 与未关联注册客户的模拟业务退出当前统计。模型成本由本组织以及明确关联客户交付的 CostEvent 估算，未开放无关客户原始输入输出。

毛利估算未覆盖人工、税费和其他经营成本。周报基于数据库状态与时间计算，所有金额和转化均可追溯，不由模型虚构。

## 审批与审计

报价与变更、重大报告问题、退款、公开发布、真实付款及数据删除分别保留审批边界。批准本地请求不等于外部操作已经完成，外部供应商和账号仍需配置。关键动作保留 AuditLog；客户只访问自己关联的需求、订单及工单。

原 Demo 模拟支付入口已停用。不要使用早期历史截图或测试脚本中的模拟流程代替 v1 当前功能说明；验收证据按日期见 TEST_REPORT.md。
