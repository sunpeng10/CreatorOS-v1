# 所有者操作与边界

Windows 桌面入口已经创建。当前桌面运行包复用本机项目环境，跨电脑安装包与 Windows 代码签名暂未配置；需要对外分发时再提供签名证书和安装目标要求。

## 本地演示

1. 使用本机 `data/admin-credentials.txt` 中的随机管理员凭证登录。普通客户可自行创建独立工作区。该文件、`.env` 和数据库均被 Git 忽略。
2. 任务书原先内含明文 MiMo Key，初次读文件时进入了工具记录。明文已从任务书移除，配置保存在本地 `.env`。请在 MiMo 控制台轮换原 Key，并在 `.env` 更新 `MIMO_API_KEY`，随后重启。若额度或模型权限有变化，在设置中核对模型列表状态，确认预算后再运行分析。
3. 在作品库与指标页导入你有权使用的实际资料。本项目自带的 TEST 与 DEMO 样例专供演示。赛题 PDF 在项目及同级参赛目录的查找范围内未找到，可复制至 `docs/reference/` 后补核对。三份 Markdown 参考材料已提炼。

## 外部授权与生产接入

- **真实付款与退款**：本地仅记录人工审查与 Demo 支付。启用实收前需由你开通合规收款账号、提供测试环境凭证和 webhook 配置，再实现并验证签名、幂等与对账；真实收款与退款由你确认。
- **外部发布、个人数据删除**：本地保存审批和执行边界。发布需要对应平台账号授权，删除需要确认对象、影响范围和备份保留策略，再执行并记录结果。
- **公开视频与 ASR**：当前对标使用手工或授权导出的资料，YouTube API 作为后续可选接入。没有启用自动转录，上传 SRT/VTT 或提供文稿即可补足。需启用时由你配置对应授权与成本预算。
- **公网部署**：如需交给真实客户使用，需提供目标环境和域名，配置 TLS、Secure Cookie、生产机密、备份、媒体隔离与防病毒扫描、生产数据库，并评审隐私说明。PostgreSQL 已提供驱动与迁移配置，尚无生产实例用于验收。
- **开发工具依赖**：生产依赖审计为 0，开发依赖审计仍有 8 项 moderate 提示，后续升级开发工具链时重新评估。

Edge 验收客户凭证保存在本机 `data/browser-edge-credentials.txt`，可用于展示已持久化的本地分析、创作实验和已完成的 Demo 订单。`data/browser-chrome-retry.json` 中为此前真实 MiMo 验收使用的 TEST 工作区，可在 Edge 打开对应报告。凭证文件均仅保留在本地。
