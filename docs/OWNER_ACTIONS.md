# 所有者操作与边界

Windows 桌面入口已经创建。当前桌面运行包复用本机项目环境，跨电脑安装包与 Windows 代码签名暂未配置；需要对外分发时再提供签名证书和安装目标要求。

## 本地演示

登录记忆首次启用：关闭并重新打开桌面窗口，保持勾选“记住登录（30天）”登录一次。后续正常关闭重开会恢复登录；主动退出或 30 天到期后需再次登录。现有旧会话不自动延长，无需重建桌面快捷方式。账号登录由本人操作，程序不保存明文密码。

1. 使用本机 `data/admin-credentials.txt` 中的随机管理员凭证登录。普通客户可自行创建独立工作区。该文件、`.env` 和数据库均被 Git 忽略。
2. 任务书原先内含明文 MiMo Key，初次读文件时进入了工具记录。明文已从任务书移除，配置保存在本地 `.env`。请在 MiMo 控制台轮换原 Key，并在 `.env` 更新 `MIMO_API_KEY`，随后重启。若额度或模型权限有变化，在设置中核对模型列表状态，确认预算后再运行分析。
3. 在作品库与指标页导入你有权使用的实际资料。本项目自带的 TEST 与 DEMO 样例专供演示。赛题 PDF 在项目及同级参赛目录的查找范围内未找到，可复制至 `docs/reference/` 后补核对。三份 Markdown 参考材料已提炼。

## 外部授权与生产接入

- **v1 工程维护提示**：发布检查通过，前端仍有 1 条分析轮询 Hook 的依赖提示（0 条 error），测试客户端另有依赖弃用提示；后续维护时处理，记录见 TEST_REPORT.md。GitHub 仓库仅保存源码版本，不会自动启动公网网站，当前本机业务数据与密钥不随仓库上传。

- **MiMo 联网核查插件**：已接入官方内置搜索，随用户确认的 AI 分析执行并计入任务预算。MiMo 账号需在控制台开通“联网服务插件”；该账号授权/计费设置由你操作。本次仅用模拟响应检查调用与费用逻辑，未变更账号设置，未确认当前账号是否已开通。若报告提示核查未完成，请按[官方联网搜索说明](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/tool-calling/web-search)检查开通情况。历史报告保留，可点“重新识别与核查”按预算重新生成；不会自动重跑或收费。

- **历史作品重名整理**：升级前已保存的数据中存在 1 组同一工作区的重复作品标题。本次保留这些作品及其原名称，没有自动替你命名或删除。新建作品与修改标题已拦截重复；历史同名作品需要你指定各自最终标题后再整理。

- **真实付款与退款**：当前已支持客户下单、老板接单、服务交付、客户验收及订单营收统计，尚未接入资金支付。原模拟支付入口已停用，旧模拟业务已归档。启用实收前需由你提供收款账号、支付服务凭证和 webhook 配置，再完成签名与对账；真实资金操作由你确认。
- **外部发布、个人数据删除**：本地保存审批和执行边界。发布需要对应平台账号授权，删除需要确认对象、影响范围和备份保留策略，再执行并记录结果。
- **公开视频与 ASR**：当前对标使用手工或授权导出的资料，YouTube API 作为后续可选接入。没有启用自动转录，上传 SRT/VTT 或提供文稿即可补足。需启用时由你配置对应授权与成本预算。
- **公网部署**：如需交给真实客户使用，需提供目标环境和域名，配置 TLS、Secure Cookie、生产机密、备份、媒体隔离与防病毒扫描、生产数据库，并评审隐私说明。PostgreSQL 已提供驱动与迁移配置，尚无生产实例用于验收。
- **开发工具依赖**：生产依赖审计为 0，开发依赖审计仍有 8 项 moderate 提示，后续升级开发工具链时重新评估。

Edge 验收客户凭证保存在本机 `data/browser-edge-credentials.txt`，可用于查看已持久化的本地分析与创作实验。旧模拟订单不再参与当前业务统计。`data/browser-chrome-retry.json` 中为此前真实 MiMo 验收使用的 TEST 工作区，可在 Edge 打开对应报告。凭证文件均仅保留在本地。
