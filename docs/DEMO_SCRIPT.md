# CreatorOS v1 · 操作演示

演示使用单独的 TEST 客户账号，样例资料来自 `fixtures/`；不使用当前真实客户的私人材料。默认先展示本地分析，MiMo 部分需所有者配置账号和预算。

## 1. 注册与登录

从首页进入注册，勾选“记住登录（30天）”，创建测试工作区。展示工作台统计卡片和对应明细。老板账号由初始化命令创建，使用独立浏览器会话或桌面窗口演示角色切换。

## 2. 研究一份作品

上传自有图片或运行 `scripts/generate_fixtures.py` 生成的 TEST 视频，可一并上传 `fixtures/TEST_字幕.srt`。填写唯一作品标题、平台、类别、文稿及背景，选择本地分析。查看步骤、真实素材预览和放大、报告与可编辑创作版本。

演示 AI 时先确认配置和预算，再使用 MiMo 深度分析。说明联网插件要求、画面识别与核查来源，以及尚未查证事项的人工审阅入口。

## 3. 积累与实验

导入明确标记的对标和指标样例，展示来源、筛选、缺失数据及统计口径。在报告修改清单选择一个建议，创建关联实验，点击查看并补充实验观察。说明建议、版本、作品与数据之间的关联。

## 4. 客户服务闭环

测试客户从首页提交需求并选择服务，或由老板创建报价并审批，再让客户确认。客户确认订单后，老板接单、回复客户、完成服务或交付报告，客户在“我的订单”二次确认验收，并在“服务与反馈”看到状态和回复。

老板查看订单金额、模型成本与周报。明确说明当前按已接单金额记账，尚未实际收付款；不要再演示旧的“模拟支付”入口。

## 5. 交付与收尾

展示报告导出、版本历史、登录记忆与所有者操作文档。测试留下的业务应在隔离测试工作区处理；不要批量删除实际客户记录。
